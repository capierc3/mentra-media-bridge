Media Bridge Captions

Live captions for phone audio (podcasts, audiobooks, video) from the TakeMotions Media Bridge app. Version 0.1.0.

Install on your phone
  1. In the Mentra app: Settings → Developer settings.
  2. Under "Mini App Development", tap Scan Mini App QR Code and scan this code.

Install in Mentra
You also need
  1. An Android 12+ phone with the TakeMotions Media Bridge app. Turn on Captions, and Enable media bridge for track info and time.
  2. Display glasses connected to the Mentra app (built for Even Realities G2).
